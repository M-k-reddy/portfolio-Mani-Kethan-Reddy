## 🚀 Local Setup & Installation

Clone the repository and install dependencies to run locally:

```bash
# 1. Clone the repository
git clone https://github.com/M-k-reddy/portfolio-Mani-Kethan-Reddy.git

# 2. Navigate to project directory
cd portfolio-Mani-Kethan-Reddy

# 3. Install dependencies
npm install

# 4. Launch development server
npm run dev
```

Open `http://localhost:3000` in your browser to view the application.

---

## 📦 Build & Deployment

To build for production and deploy to GitHub Pages:

```bash
# Build production bundle
npm run build

# Deploy to GitHub Pages
npm run deploy
```
